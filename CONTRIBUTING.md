# Contribuir

## Flujo

1. Abrir issue.
2. Crear o actualizar ficha.
3. Modificar `catalog.json`.
4. Ejecutar `python scripts/generate_readme.py`.
5. Actualizar comparaciones y coverage map.
6. Actualizar `CHANGELOG.md`.
7. Ejecutar `python scripts/validate_catalog.py`.
8. Crear pull request.

## Calidad

- Fuentes oficiales.
- Fecha de revisión.
- No copiar marketing sin análisis.
- No confundir UI demo con funcionalidad.
- Documentar cuándo no usar una opción.
- Registrar trabajo de curación.
