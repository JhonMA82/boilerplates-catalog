# Decisión pendiente de licencia

No se incluye un archivo `LICENSE` porque todavía debe decidirse si el catálogo será privado, público con MIT, documentación Creative Commons o una combinación.

Antes de publicar:

1. definir uso esperado;
2. separar licencia de scripts y documentación si corresponde;
3. revisar que no se copie contenido incompatible;
4. agregar licencia mediante un ADR.
